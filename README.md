Our favorite **WORDLE**:

My love for Wordle starts way back, when I was around 8 years old and my brothers gifted me the game *Mastermind*, a similar game that we played for hours with my family!

Just run `python .\gui.py` and enjoy `:)` 

**How to play**:
- Guess 5-letter words
- Green box means correct letter in the correct position
- Yellow box means correct letter in the wrong position
- Gray box means wrong letter
- You have only 6 attempts
- Good luck!
